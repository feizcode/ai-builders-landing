# AI Builders Landing Page

یک لندینگ آزمایشی فارسی برای معرفی AI Builders. این پروژه فقط از HTML و CSS استفاده می‌کند و برای GitHub Pages آماده است.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید.

## انتشار در GitHub Pages

در تنظیمات مخزن GitHub، به **Pages** بروید و گزینهٔ **Deploy from a branch** را انتخاب کنید. شاخهٔ `main` و پوشهٔ `/ (root)` را برگزینید و ذخیره کنید.
